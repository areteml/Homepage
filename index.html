How we build

We'd rather you run a model than admire its parameter count.

Speed first

Every model gets its own multi-token prediction head, trained in from the start. Mid-size models use mixture-of-experts so only about a billion parameters work on each token.

Quantization is the target

Every tier is designed to be run at Q4_K_M. That's the version we test, tune, and size against real GPU memory, not round numbers.

Open, on a delay

The newest flagship lives behind our API. Once two newer generations ship, its weights go public, so older models are always open.
